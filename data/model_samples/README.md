# data/model_samples/

One raw sample response per model provider, saved by the corresponding
Day 5 connectivity script in [`../../initial_tests/`](../../initial_tests/README.md).
Purely for inspecting each provider's response shape before the real
extraction prompts were built — not used by any experiment script.

- **claude_sample_response.json** — from `test_claude.py`.
- **deepseek_sample_response.json** — from `test_deepseek.py` / `test_deepseek2.py`.
- **gemini_sample_response.json** — from `test_gemini.py` (Gemini was later
  dropped from the project; kept for reference).
- **openai_sample_response.json** — from `test_openai.py`.
