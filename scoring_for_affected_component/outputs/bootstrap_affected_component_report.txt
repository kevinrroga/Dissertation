INTERPRETATION NOTE
------------------------------------------------------------------------------------------
Overlapping CIs between two cells indicate that the difference in
accuracy is consistent with sampling variation and should not be
interpreted as a reliable performance gap. The McNemar test provides
the formal paired significance test for each comparison.

The relatively wide CIs here (compared to attack_vector and CIA)
reflect the genuine difficulty of this entity: 500 CVEs is sufficient
for the closed-class entities, but open-ended extraction accuracy
is more sensitive to which specific CVEs happen to be sampled.
